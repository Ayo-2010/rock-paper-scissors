# Rock Paper Scissors

Play rock, paper, scissors against the computer.

## Features

- Play to 3, 5 or 10 wins
- Animated hand shake and coloured round feedback
- Keyboard shortcuts: R, P and S
- Score tracking with a win overlay

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
